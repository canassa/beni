-- The .beni files `zig build beni-fmt-check` does not hold to `beni fmt`'s
-- output (language.md §12.5, frontend.md §11.6). One glob per line, then
-- ` -- ` and the reason. `**` matches any run of characters, `*` any run
-- without a `/`. An entry naming one file must name a file that exists and
-- that `beni fmt --check` refuses, or the step fails: delete it then.

tests/corpus/parse/bad/** -- files that must not parse
