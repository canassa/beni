\chapter{The Rules' History and the Programs That Shaped Them}
\label{app:history}

The rules of Chapters~\ref{sec:model}--\ref{sec:hard} reached their present form in five steps, each
prompted by short programs that the previous form accepted although their in-place run differed from
their value-semantics run, or that it rejected although they were idiomatic. We record the steps here,
once, so that the body of the thesis can state the design it defends. The programs are those of
Table~\ref{tab:counterexamples}.

\paragraph{First form.} The rules as first written had the four side conditions, per-path liveness and
summaries with three facts per parameter. Programs T1--T6 were found while writing them: aliasing between
a call's own arguments (\Disjoint\ was added), the optimiser folding a read across a write (A5), a
top-level value as a holder, an event payload that is a model list, a once closure passed twice, and an
unknown result read as ``no cell''.

\paragraph{Second form.} An adversarial reading of the first form found programs T7--T19. Closures lost
their captures and their once-ness when they were returned, stored or captured, because both were
attached to the binding that named the lambda; environments at $\env$ and once closures as cells replaced
that. \code{supply} carried no provenance, so a callback that returned its argument looked fresh (T15).
A user \code{eq} could write behind \code{==} (T9). Exclusive contents ignored aliasing inside one element
(T10). A building loop returned its argument while its summary said fresh (T12). The entry protocol
covered \code{update} alone, read bodies no interface carried (T16), and ignored the hold of a value
\code{init} (T14). Pending operands were not holders (T17), a view cached a stale copy (T18), and opaque
types were assumed to cross (T19). In that form, list syntax was made to build new arrays, so that
spreading a list still in use was not an error; a warning marked accumulators that copied.

\paragraph{Third form.} A second adversarial reading found programs T20--T32. Summaries could not say
that a result's cell had escaped inside the callee, came from a top-level value, or was unknown, so a list
captured by a command and then returned looked fresh to the entry protocol (T20--T22). A closure that
returned what it held gave results that looked fresh (T23--T26). A once closure that escaped to the
runtime was never checked again (T27). Foreign types were assumed to cross, hiding markup handlers'
captures (T28). An optional platform promise that commands which cannot suspend run before the next
message was found to contradict the platform's dispatch order, under which a command body's send is
dispatched at once (T29); it was dropped, and commands' captures are escaped. The entry protocol's place
was ambiguous for a program mounted twice (T30). Local functions used before their line were outside the
model (T31). Keys and values of a dictionary shared one opaque step (T32). The same reading found that
making list syntax build reversed the language's linear-prepend decision and turned accumulators
quadratic, that dropping the identity promises reversed the decision the renderer relies on, and that a
consuming \code{send} rejected programs with no in-place edit.

\paragraph{Fourth form.} The fourth form answered the third reading and turned the design around a
different question. List construction consumes a base chosen by position (Change~1), so accumulators,
folds and \code{update} arms run in place, and the warning on copying accumulators goes with the copying.
The identity promises are kept, and their aliases appear in summaries. \code{send} writes what
\code{update} writes (T34). \code{init} is a function and top-level lists are shared (Change~4). The
renderer obligation \Obl{P7} takes the label the dropped command promise had. The idioms of
Chapter~\ref{sec:idioms}, and the frequency of the error on them, became the measure the design is held
to; T33, a persistent stack whose versions are kept, records the one part of the linear-prepend decision
that construction-as-consumption cannot keep without an explicit copy.

\paragraph{Present form.} A third adversarial reading of the fourth form found no accepted program that
observes a write through the checker's own rules, but four holes at the boundary with the platforms and
three idioms the thesis said must pass that its rules rejected; programs T35--T45 record them. The
renderer obligation \Obl{P7}, as the fourth form stated it, covered only the template runtime's
\code{<For>} skip, though that runtime skips by identity in grouped values, \code{let}s, helper calls,
components, \code{Show} bodies, row inputs and views (T35, T36); and the direct platform, said to keep it by
design, guarded its indexed scripts by element identity, which an element edited in place defeats (T37).
The author then decided that in-place lists are a feature of the direct platform only (rule~7 of
\S\ref{sec:bg-language}): the template runtime keeps its skips and its persistent lists, and \Obl{P7} was
restated over every identity test the direct platform makes, with the parts it must add. The send rule bound
a send to \code{update}'s own use of the payload, which misses a payload stored by one arm and extended by
another (T38); a send now follows its payload to the paths it reaches. The escapes that \code{view} makes
were in a table but not in the entry protocol (T39); they are now, and on the direct platform they are none,
by \Obl{P3}, which was widened to markup values. Closures captured whole variables, which rejected the
example application's appends because a command read \code{model.session} (T45); captures are now per path.
The exclusive-contents flag did not survive a record update of an element, and neither \code{Dict.update}
nor the folds carried it (T40, T44); ``keeps shape'', the asserted exclusivity of \code{Dict.update} and the
folds' guard repair that, and the same argument gave \code{map} a single-pass row that accepts an edit by id
(T42). The same reading found that a chain of \code{++} consumed its middle operand under the language's
right-nested lowering, now flattened (T43); that an undo of a list needs a second copy (T41); that the order
on provenance sets had been mis-stated; and that the evaluation's main metric counted only forms already
known to pass, and called rejections ``real'' that read no old version.
