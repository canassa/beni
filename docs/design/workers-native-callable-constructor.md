# One checked native constructor: implementation boundary

Normative proposed implementation contract, 2026-11-01. This refines
workers-native-bindings.md and workers.md; review this boundary before compiler
implementation. Baseline is frozen be99c406745374979db981d3a6efc6f9452136ec.
No ownership rule, source keyword, builtin, native-shaped TypeStore variant,
manual trusted wrapper, source cap or budget exemption is introduced.

## Exact callable and evidence

Only Browser.Host.TextEncoder exports a callable in this slice:

```beni
pub foreign type TextEncoder
pub foreign impure new : ⊤ → TextEncoder
```

The generator creates both declarations, and the ordinary frontend/checker
checks them. The authoritative effect is existing Bir.Rung.impure, ordinal1;
Effects.foreignSummary produces the root class and ordinary instantiation/call
inference carries it. No synthetic rung-only certificate replaces checking.

The source identity is @webref/idl3.86.0 digest
f820cd04584ca7f815b8cee1381d76e27363090cd62e0cb88962d8188bc7c90a,
package/encoding.idl TextEncoder constructor(), overload0. The primary Encoding
algorithm https://encoding.spec.whatwg.org/#dom-textencoder defines no expected
constructor failure. Row policy is expected-error none, unexpected failure defect;
not noThrow, and no catch or feature-detection fallback is added.

Realm bits follow explicitly versioned names window,dedicatedWorker,sharedWorker,
serviceWorker,node at positions0..4. WebIDL Exposed=* plus pinned Global
attributes establishes the four web realms. Node's independent intrinsic source
is https://nodejs.org/download/release/v24.19.0/docs/api/globals.json, retained
SHA47f15d2c6395318e04d4038fefafbcbda59a054238dd18045dc333d229e9488a.
The resulting seed is0x1f. This is supported-host exposure, not a guarantee against
replacement/missing globals. encode/Uint8Array and every other callable stay
adapter_required. Native object representation remains the object itself.

## Records and proposed APIs

`native/Bindings.zig` owns immutable compiler-pinned definitions and a per-Session
Registry. All names below are proposed interfaces, not claims existing code has
these functions. The catalogue remains type metadata; callable schema1 is a
separate version and a cache/public-interface revision changes when installed.

- NativeTypeKey: source revision, IDL identity, generated module/type symbol and
  canonical declaration/source digest. Attest TYPE as well as callable identity.
- BindingKey: NativeTypeKey, member kind constructor, overload0, original source
  span/digest, ordinary scheme digest, effect rung1, realm source revisions+mask,
  adapter revision, expected-error policy and direct recipe constructGlobal.
- GeneratedOrigin: compiler-owned generation receipt, bytes digest and pinned
  row-set digest. Created only from verified pinned generator input/output;
  source pathname, package.core, isEmbedded or a JSON self-hash cannot create it.
- InstalledType: NativeTypeKey plus resolved graph module and ordinary TypeId.
- InstalledBinding: BindingKey plus resolved module/declaration/scheme indices,
  InstalledType ID, root effect class/site and realm summary ID.
- Registry: dense immutable rows, indexed exact module/declaration and TypeId
  lookups. IDs are Session-local. Serialized records contain stable keys and
  bounded indices, never pointers or stale module ordinals.

`prepareModule(request, pinnedCatalogue, arena)` produces only the requested
ordinary module bytes and GeneratedOrigin. `validateModule(origin, source,
bir, iface)` checks exact definitions and resolved nominal/scheme provenance;
`install(registry, validated)` publishes atomically. Cache installation performs
the same checks before exposing type or callable rows. Failed checks produce no
partial registry entries. Source/revision/signature/effect/realm/recipe identity
participates in interface fingerprints and reverse-user invalidation.

An APP shadow, physical core_root override, edited generated file or forged cache
must resolve without generated authority or fail validation. Equal spellings,
foreign signatures or embedded bytes do not inherit a previous registry ID.
SourceStore.addEmbedded is a borrowing primitive, NOT the attestation boundary.
Session-owned generated bytes/rows outlive SourceStore/interface/worker readers;
workers receive immutable registry views after installation. Session resets clear
all installed IDs before graph/artifact replacement. Module lookup is indexed;
importing TextEncoder never checks the complete generated package.

## Realm producer and actual consumer

This is an independent component alongside existing effect classes, not another
meaning of rung1. Proposed `check/Realms.zig` owns:

- ClassFact(class identity, allowed:u8, dependency range, source witness);
- Dependency(source class, target class, lexical scheme/path binding);
- Summary(owner scheme, class/path rows, unresolved dependency rows);
- EntryDemand(selected Plan kind, executed root, source witness).

Class identity is the ordinary solved function/evaluation class, including exact
lexical owner and instantiation. It is not merely a function type or matching
signature. Reuse Effects' recorded call/instantiation/alias/nominal callback
relationships only through an explicit lifetime-safe view. The publication API
maps solved class IDs to ordinary scheme paths; installation verifies path bounds,
class membership and dependency references using existing scheme authority.
No source-native identity or unresolved callback fact is erased into Js.Value.

`solve(view, bindingSeeds, scratch)` intersects masks through actual call and
callback dependencies with a worklist/SCC schedule. Each fixed bit is removed at
most once per class; propagate unresolved variables as dependencies rather than
assuming all-realms. `publish(owner)` produces stable scheme-relative rows.
`instantiate(summary, ordinaryBindings)` retains exact callback/alias substitution;
`checkEntry(selectedPlan, executedRoots, summaries)` discharges actual reachable
obligations and reports a forbidden realm or explicit unresolved proof.

Executed roots use the existing selected entry/runtime and evaluated initializer
policy. Unreachable declarations do not reject; a deferred function is not
mistaken for its initializer. Recursive calls use monotone fixed points. Exported
library functions retain obligations for later uses. A bare seed0x1f is NOT an
exemption: the actual constructor summary must be installed, propagated and read
by this consumer. Narrower compiler-test rows exercise refusal; they do not change
the production constructor's legitimate realm set.

Unknown raw-host intrinsic behavior/callback obligations must remain visible as
residuals wherever this proof requires them. Do not advertise complete C,
EntryHost, owning storage or launch merely because the constructor obligation
passes. No public worker gate activates here. Existing raw-host migration remains
outside the one-callable implementation; missing required evidence cannot become
a positive full-entry certificate.

## Bounds and ownership

Let V/E be actual ordinary realm classes/dependency edges; fixed-universe solving
is O(V+E) times five bits. Catalogue lookup and installed row construction are
indexed in actually loaded rows/source sizes. Store dependency edges once per
ordinary recorded binding, not per environment Cartesian product. Serialized
path words are charged as original published records; derived expansion is not
renamed input to hide costs. No new arbitrary W/cap or source rejection threshold
is allowed. If ordinary substitution cannot meet the decided schedule, retain the
counterexample and stop for design review before adding a workaround.

Rows and dependency sidecars are owned by the Session/check result appropriate to
their lifetime; borrowed effect-store class IDs never survive its destruction.
Exported/cache rows use scheme paths and stable keys. All allocation failures
release partial owned tables; generation/validation/entry refusal precedes positive
output. Existing filesystem/I/O failure conventions remain unchanged.

## Lowering and strict first-class semantics

Add a validated BindingId consumer to existing Lower/Reach/Emit paths. It emits
existing JsIr.new_call with global TextEncoder and zero host arguments. A fully
applied ordinary unit argument is nevertheless evaluated exactly once before
construction via existing sequencing/discard rules. Preserve impurity through
Spec: no CSE, duplication or reordering of construction.

A first-class Beni `new` is an ordinary emitted callable facade with that direct
body; it is not the host constructor used as an ordinary JS function. Use existing
calling conventions, no dynamic universal apply and no per-object native wrapper.
The same BindingId authorizes absence of a handwritten foreign sibling and the
actual lowering; no module-name-only guard or trusted source Js.global wrapper.
No handwritten JS is introduced, including tests.

## Phase 1 source-supplier seam (before implementation)

Initial implementation uses `native/Source.zig.Origin` as a closed compiler-side
supplier tag, default none, in SourceStore.Pending and File. It is NOT a certificate
by itself: Bindings validation must also match canonical source/type/callable
records and ordinary checked interface. addEmbedded always supplies none;
addGenerated is the explicit compiler producer hook. `finish` transfers the tag
with the winning bytes and clears it if any physical supplier wins. It never
merges the strongest package's origin. Equal physical bytes still clear it.
No serialized source/cache bytes can set this tag. Phase1 installed bindings have
status awaiting_realm and are never lowerable or public-callable-ready.

Realm refinement: the future RealmVar/CallablePort identity is independent of
TypeStore union roots, Effects.nodeFor and nominal holder classes. Equal ordinary
function signatures/rung1 do not merge two independent execution identities.
Ordinary effect events are reusable only where they record actual flow bindings;
pure-class omission in EffectsBlock does not omit realm facts. Distinct evaluation,
lambda/declaration execution, returned-function and parameter/result ports and
source-owner bindings must survive publication. A separate reviewed phase2 API
will pin those hooks; phase1 may not seed a native realm using collapsed effect
class identity as callable provenance.

Phase1 generator row: a fixed record carries schema/adapter revision, native
identity enum, source/member offsets, IDL digest, generated-source digest, realm
source digest, ordinary rung and realm mask, expected-error enum and awaiting_realm
status. Only generate's successful pinned-archive path adds this row; the general
IDL index helper does not attest arbitrary test input. Ordinary catalogue module
printing emits the callable signature only for that verified row's selected type.
The complete generated bytes are canonical input to later Bindings validation.

Phase1 ordinary checker seam: `Bindings.validate(origin, source, module_name,
package, bir, iface, interner)` returns nullable fixed Checked row with declaration,
interface-type and scheme indices, status awaiting_realm. It checks exact canonical
source, BIR foreign type/value declarations, public Interface foreign nominal,
unit argument/nominal result, and actual published root effect class rung1 with
no dependencies. The caller must provide already structurally verified Interface
(fresh ordinary checking or common cache reader); arbitrary malformed bytes never
reach unchecked sidecar readers. No origin returns no binding. Both cache and
fresh paths must pass this same predicate before native registry publication.

Phase1 cache publication seam: Check.Options borrows current SourceStore only for
native-source validation. Driver checks the loaded ordinary Interface with
Bindings.acceptsCached BEFORE Incremental.install replaces the shell. Session
publishes Registry after the same validation on fresh/installed interfaces, into a
temporary registry then atomic assignment; resets it before each run/store change.
The current singleton identity is indexed by the closed Origin enum, not a source
count cap. Native-source own keys and exported interface fingerprints include the
versioned provenance domain (IDL/Node/adapter/signature/effect/realm/status); no
cache record can restore a source supplier origin. Physical identical-source keys
and exported fingerprints stay distinct. This adds no serialized pointer or new
public Interface field in phase1; native provenance is an additional existing
fingerprint term and registry is rederived from source authority every run.

The actual pinned generator emits TextEncoder.binding.zon alongside the catalogue.
Its small exact output is retained as src/native/TextEncoder.binding.zon and
compiled as Source.candidate. The generator regression compares the real parsed
candidate row against that compiled record; no runtime catalogue parse is needed.
The entire generated snapshot also participates in the provenance fingerprint.
Bindings validates this candidate's digest/rung/status before ordinary type/effect
validation, and Installed retains that same candidate for downstream realm seeds.
No source-supplied or cache-supplied candidate replaces the compiler-owned snapshot.

Phase1 emission denial is explicit: existing emitter contract validation reports
not_implemented for an installed awaiting_realm callable before inspecting any
foreign sibling or starting projection. A user-created physical JavaScript
sibling cannot enable the compiler-owned candidate. This denial is removed only
when the complete checked realm/lowering pipeline is accepted, not when a fixture
happens to contain a global constructor. Ordinary untrusted source remains under
ordinary existing foreign rules and acquires no native identity through them.

### 2026-11-01: reproducible allocation coverage and isolated attestation setup

The prepared-inspector allocation sweep exercises every relocation allocation
with in-place resize/remap disabled in its test backing allocator. Ordinary-GPA
preparation still runs and its exact bytes are compared with every successful
sweep invocation. The pinned standard allocator sweep counts allocations, while
backing layout can replace one allocation with a successful resize; such layout
variation must not skip a failure position or be mistaken for a resource leak.
No production allocator, allocation ownership, or test budget changes.

The attestation unit fixture checks the canonical generated native supplier in
an ordinary Session with the exact ordinary String foreign declaration and its
separate Other nominal. It does not load unrelated core modules or request a
realm graph merely to validate registry metadata. All supplier, nominal,
namespace, effect, totality and cache-admission assertions remain. Packaged CLI
coverage separately exercises the complete core installation.
