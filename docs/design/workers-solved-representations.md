# Ordinary solved representation provenance

Implementation specified 2026-11-01; milestone A of #1296. This is owned diagnostic authority, not HostFree, Wire, transfer ownership, entry discovery completeness or transport permission. [workers.md](workers.md) sections 4/5 remains normative; no guarantee or source bound changes.

## 1. Publication point and demand

Only the existing hidden checked-entry inspector requests this inventory. Ordinary check/build and zero requests do not allocate a capture, graph map, snapshot or validation registry. A requested clean module publishes after its ordinary P9 entry roots, nominal templates and source evidence have finished reading the ordinary store, before ownership passes and Driver store release. Own/dependency errors, quiet checking, setup failure and reset clear evidence to absent. An absent requested cache artifact is a normal source repair, never an empty proof.

The publication owner borrows final Preparation parameters, source schemes and writer canonical alias roots only during P9. Captures copy Var IDs and scope/formal rows immediately; temporary arrays never escape. Entry roots retain original quantifier order and point to their already-owned EntryRoots scheme; nominal scopes retain ALL final declaring parameter positions including phantom slots, and point to their NominalLayouts owner; canonical ordinary alias scopes retain their actual distinct reader formals and declaring TypeId, plus the exact existing entry-versus-nominal artifact and TypeRef row whose canonical body was read. Schema endpoints retain their explicit unavailable layout states rather than being relabeled ordinary alias bodies. No scan of annotation names reconstructs binders. Canonical alias-reader formals are recorded as actually read; declared owner key/kind authority remains the resolved declaring Types row, not an assumption that every fresh reader formal already carries every owner bound. Original kinds, identity/crossing bits, constraints and effects remain authoritative in their existing ordinary scheme; this artifact does not invent replacement givens.

## 2. Concrete inventory and accounting

D is the ordinary TypeStore's allocated descriptor count at this precise point. T_store is the count of representative descriptors (parent=self), including ordinary publication allocations already present. E_store counts each representative's ORIGINAL structural successor occurrence once, and F_store is its record-field subset. T_store is NOT D, nominal TypeId count, serialized terms, cursor views, source instructions or an invented set of specialized payloads. Record both D and T_store, plus parent edges visited by canonicalization, graph edges copied and original/template root counts. A stored provenance node is one actual representative Var in this module at this publication point; no derived template instruction receives such a source ID.

The store-copy phase performs an explicit O(D+E_store) construction. Original captured scope roots R and formal-binding words Q are copied once each as separate original input work, so complete artifact construction is O(D+E_store+R+Q); no unproved R/Q-to-D inequality is assumed. The dense descriptor-to-representative memo is initialized once; an iterative parent-chain walk memoizes each descriptor once, without mutating the ordinary store. Representatives are ordered by original source Var. Copy original nodes and sidecar edges through that memo using existing Walk.child/stepped accessors (no new privileged child reader); do not instantiate or expand a type while constructing the graph. Alias.actual is the pre-existing actual graph edge. Nominal arguments are pre-existing argument edges; constructor specializations are NEVER generated. Cache artifacts retain source descriptor IDs as provenance, not live Vars that may be dereferenced after release.

This settles the A construction cost honestly: O(D+E_store+R+Q) time and O(D+T_store+E_store+R+Q) memory, with all scans charged and visible. It does NOT prove a future HostFree classifier costs O(T_store+F_store), and must not be presented as doing so. A future canonical classifier receives the already-owned graph and can traverse it in O(T+E), but its end-to-end construction accounting remains a separate review obligation. No D scan is silently charged to canonical T, and no late counter is substituted for a complexity proof. This diagnostic milestone does not run a classifier.

In addition to whole-store counts, the consumer computes a shared reachable union from selected ordinary entry roots and captured template roots, reporting distinct node/edge counts. It retains original root incidence; derived root-times-role output is not an input denominator. The Matrix and sparse kind/vector families compare ACTUAL D/T/E with the compressed EntryRoots terms and cursor output. No expansion ratio is itself a budget violation.

## 3. Owned data and template distinction

SolvedRepresentations.Artifact owns flat SoA node/root/scope rows and shared u32 edge/formal/descriptor-map sidecars. Node indices and source IDs have separate enum types. A node records its original source representative, content tag, native/nominal identity reference where applicable, variable kind/rank and marker_eq metadata (the source variable marker, never the nominal type-table equatable gate), and successor range. Record edges retain the exact interned field symbol. Functions retain parameter/result edges; aliases retain existing actual and diagnostic argument edges distinctly. No pointer, per-node allocation, dense-ID hashmap, fresh solver node or caller-environment product is permitted.

Root kinds distinguish original entry schemes, final declaring nominal template bundles and canonical alias bodies. Templates may use real ordinary Vars allocated by existing publication; that provenance is real, but their role remains TEMPLATE, never an instantiated concrete payload. A shallow alias placeholder is tagged as unavailable to any later semantic consumer; an err node can appear in whole-store diagnostic inventory and is never treated as a safe leaf. Native/schema layout kinds remain explicitly unavailable. A formal mapping is scoped by its actual root/declaring binder, not just its numeric Var or Interface.var ordinal.

The artifact is Module/Dispatch owned and cleared before every replacement or fallible setup through central clearEntryEvidence. Query owners borrow it and deinit before Session reset/recheck. OOM propagates; user/dependency errors produce no internal metadata error. Root/capture construction failure cannot publish a partial usable artifact.

## 4. Private format and common installation

Add a versioned private solved-representations column to dispatch format; unknown versions are cache misses. Production cache loads explicitly carry whether this hidden inventory is requested. Unrequested loads validate the enclosing column envelope but do not decode/allocate its diagnostic graph, including entries previously populated by an inspector. The loader still reads the enclosing BEC bytes and mandatory shared refs/string tables; skipped graph decoding is NOT zero byte, RSS or overall cache-load overhead. Report query-populated default-load resources separately from default-produced cache bytes. Requested loads decode and validate it strictly. Keys and ordinary option recipes are unchanged. Direct roundtrip/codec reads continue decoding all present evidence. All existing dispatch interning runs FIRST. Graph-only refs/field strings are collected only after every legacy term/head/boundary/debug row has interned its refs, immediately before ref/blob serialization. Every old type-ref ordinal and string/module-ref offset remains byte-exact; new table entries are append-only and tied to actual graph references. Native/nominal references serialize through the existing stable declaring package/module/type table; symbols serialize through the ordinary dispatch string table. The private solved header is 48 bytes; node/edge/root rows are 32/12/32 bytes, followed by formal and descriptor-map words. Root origin names the existing entry or nominal artifact; its anchor is the original scheme for an entry/template or the exact TypeRef for an alias body. No global TypeId or Symbol ordinal is a portable identity. Node IDs, descriptor IDs, root/formal indices and source declaration IDs remain explicitly distinct columns.

Resolve stable refs once into artifact-local indexed memo arrays, not once per solved node and not via global-TypeId-sized maps. Validate exact sizes, padding, enum variants, all ranges, unique ascending representative source IDs, complete descriptor map, representative self mapping, exact observed D/T/E/F totals and root/formal bounds before installation. Validate requested source coverage against BIR, current declaring type identity, EntryRoots selection and NominalLayouts root/arity. Existing private scheme validators continue to validate binder/kind/constraint/effect authority. Cache miss/source repair applies equally to directory, embedded, cutoff and roundtrip paths; decoded graphs are installed transactionally. No cached source IDs can be dereferenced as current TypeStore Vars.

This is diagnostic evidence, not an adversarial substitute for type checking. Cross-artifact semantic proof validation and private layout ABI proof-cache dependency closure are outside A; no proof is cached from this inventory. Ordinary public interface bytes and emitted JS remain unchanged. Default unrequested capture adds only an absent-format representation and request checks, with no graph traversal or allocations.

## 5. Existing hidden consumer and validation

For a requested inventory, preflight presence of every installed module artifact BEFORE the first existing inspector byte is written. Missing requested evidence makes the direct writer return MissingRepresentations with zero output. This is a narrow unavailable-input guarantee, not general OOM/I/O atomicity and not a claimed normal-CLI failure. Append a uniquely delimited solved-representation section AFTER all existing --entries output. Print actual module/declaring identities, root kind/scope/formal provenance, node/source IDs, whole-store counters, shared reachable counters and explicit hostfree=false wire=false. The consumer reads installed owned bytes after the ordinary stores have been released; it does not rerun the type reader or demand keep_type_stores.

Required real CLI controls: private/generic/phantom/alias binder authority; unchanged prior inspector prefix; cold/warm source0 and byte-identical jobs/roundtrip/relocation; baseline-exact old requested-cache columns/ref+string prefixes, and a new unrelated earlier module with old imported graphs relinked through actual declaring identity; source-cache malformed count/range/owner/formal mutations repair then warm0; unused private templates; dependency error->restore and Session reset; accepted deep/shared aliases; real Matrix and sparse kind/vector ordinary denominator receipts. Every claimed positive baseline and candidate must exit0 with nonempty expected evidence. Pure codec validation/fuzz/OOM helpers are normally registered; no zero-test acceptance.

Structural controls assert each descriptor is canonicalized once, each parent edge is charged, each representative node and original edge is copied once, and a warm installed graph performs no source store reconstruction. Zero-demand runs allocate no graph/capture/map. Parent reviews focused results, actual source/cache/byte/RSS costs and full gates before acceptance. No full-suite or optimized run starts without coordination.
