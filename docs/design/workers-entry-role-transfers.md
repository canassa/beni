# Owned anchored callback transfer producer

Normative bounded first milestone of #1295, on accepted6bb3f0f7eaef9619abc4be3ec63cf7277111015e. This extends the existing workers-entry-compact.md anchored U/B role algebra. It publishes existing solver authority and original source relations; it does not implement new formal invocation semantics, execute actual-value callbacks, or enable native lowering/worker launch. All existing public acceptance/refusal and proof flags remain unchanged.

## 1. Exact directory and identity

CompactGraph owns a RoleTransfer fixed-SoA directory with typed RoleTransferId. Each row contains entry, exact entry AnchorId, constructor OriginId, role ordinal, selected callback OriginId/template, solver SeedId, original source PortId, W and S QueryIds, its capture-row range, callback/runtime tag and existing StaticStatus. The row is created in CompactDiscover.callable, alongside the seed and callback/capture bindings. It cannot be reconstructed by source-site/role/type/name equality.

Capture rows additionally retain their RoleTransferId, exact original typed BindingId and paired W/S QueryIds. The BindingId is obtained at production from the existing (seed,input) composite directory immediately after bind; validation uses that direct owned row, never a captures×bindings scan. Their existing InputId remains the original owner-scoped capture index, including its source local/defining port retained by the source sidecar. A transfer's range covers only its own contiguous capture rows. Runtime seeds are retained with runtime tag and existing runtime formal bindings, never confused with ordinary callback arguments. Existing runtime watches have no overall paired S query: retain S=none/status=unproved rather than add an analysis query or manufacture static proof.

The selected Program identity remains EntryId+AnchorId: foo=make first and bar=make second may share constructor/lambda/record sites but must keep distinct anchored profiles. Alias forwarding preserves the original bound anchor; mixed B(foo,o)+U(o) at a declaration retains both correct profiles. Graph.finish remaps transfer EntryIds with all existing entry-indexed directories, while AnchorId, source and solver IDs remain unchanged. No site-only fallback is permitted.

Structural pairing checks use the COMPLETE original Observation record: W versus S may differ ONLY in mode. Role source watches and capture source queries are currently produced with ask(source, observation, none), so their effective seed must be none; the callback invocation seed is a different field and must not be substituted for this request. Each capture W/S observation equals its role's original W observation with capture=input and the corresponding mode, including original control/selector/prefix/kind/constructor/anchor fields. Its BindingId must name exactly (role.seed, capture.input, capture.W, capture.S, runtime=false), and raw capture.status must equal the owned S-status cell. Role S likewise matches original W fields except mode and its raw status cell. This is exact structural producer-domain validation, not local answer-equation certification.

Before interpreting target namespaces, role.origin must have function/closure tag and target the recorded template. A callback constructor must have constructor tag, a valid ConstructorId target whose origin back-reference agrees, matching constructor/anchor/entry/observation kind, and the exact declared dense role-position slot. Tags such as runtime/opaque/literal never reinterpret their numeric target as a TemplateId. Domain mutations are covered under #1556; this adds no answer-equation proof.

## 2. Owned original source sidecar

A new CompactEvidence helper owns an immutable copy of the original Compact source IR directories and extra u32 words, once per discovery. This retains original ports/owners/sites, templates and body/input ranges, Input.defining/source_local, origin target/template/allocation, original Call.arguments/captures/target, allocation/base/shape/field rows, selectors, constructor roles and declaration seals. IDs index exactly the copied original directories; ranges never borrow builder storage. No input receives caller actuals and no source row is duplicated per role or environment.

The sidecar also owns current solver Query, Fact, Edge, Seed, Binding, Obligation and derivation directories plus finalized static statuses. Observation/Answer IDs refer to the Graph-owned observation/answer directories already copied by snapshot. Fixed rows contain typed indices only; temporary Input/view wrappers may borrow the owning evidence only during a call. No TypeStore Var, builder pointer, phase slice or reconstructed binder identity is published.

Copy into a temporary owned Evidence object and install only after all allocations succeed. Snapshot, graph reset/deinit and all error paths free every new allocation. A failed discovery cannot leave a previous run's transfer authority usable. Source/capture accesses after discovery returns or phase arena growth must still resolve correctly from owned arrays. Session reuse clears rows before capturing a new checked store.

## 3. Shared exact derivation relation

Make solver FactId/EdgeId and fixed Fact/Edge/Obligation row types readable by the owned snapshot. Add typed DerivationId and fixed Derivation rows keyed by (target FactId, source FactId or none, via EdgeId or none). A direct published fact records the direct alternative; each delivered copy/seal/actual fact records its exact source fact and original subscription edge. If an equal answer/fact already exists, retain the new alternate derivation rather than choosing the first path as universal authority. Cycles remain graph edges, never proofs obtained by revisiting a node.

Ordinary source-call substitution currently receives a symbolic Input fact then subscribes its exact actual query as a generic copy. Retain a separate fixed TransportWitness relation pointing to that EXISTING copy EdgeId and retaining original substitute EdgeId, CallId, formal InputId and triggering formal FactId. The original edge must be substitute with matching call, source=formalFact.query and target=copy.target; source seed must match the existing ask rule (retain target seed only when its template owns the actual port, otherwise none). Its source/target QueryIds are the existing actual/consumer queries. Do not change semantic EdgeKey, subscriptions or solver work counts merely to attach provenance; no facts, roots or accepted sources change. Several witnesses may point to one deduplicated copy edge, and all remain explicit alternatives. Validate/cross-check input.owner==call.target, argument-versus-capture range, input.position bounds and exact selected actual PortId. Preserve the target seed and original observation. This makes actual argument/capture provenance inspectable after return without expanding paths or environments.

Seed binding copies retain their existing Binding index on a binding TransportWitness referencing the existing copy edge, so the source W/S query and source formal query can be joined to the actual (seed,input) row. Runtime bindings remain explicit runtime-external evidence; absence is not a closed capture. Seal derivations retain exact SealId/AnchorId transitions, including forwarding already-bound values. Original projection ports/selectors and S obligations remain in the source/dependency graph, not expanded selector strings or path tuples.

Validation in this milestone is explicitly STRUCTURAL: bounds, query/fact/edge incidence, exact original actual/binding transport relations and anchored directory ownership. It does not check every local answer equation for copy normalization, seal or non-input substitution, and does not rerun the solver. Evidence.semantic_validation is permanently unavailable; raw existing StaticStatus rows are producer observations, not validated proof receipts. A valid-index AnswerId replacement in the same query may pass structural validation and must be labeled outside the supported validator domain; no proof-like consumer is implemented or authorized to use it. Any later consumer must first establish separately reviewed exact local answer/obligation authority or explicitly refuse this unavailable semantic validation. Tests retain that limitation rather than falsely claim full tamper certification.

## 4. Bounds and accounting

Let R be original source directory/range cells; Q/F/E/D/B/O be existing solver queries, facts, subscription edges, distinct edge/fact deliveries, bindings and S obligations. Source copy costs O(R); solver sidecars cost O(Q+F+E+B+O). Derivation storage is at most one direct row per fact plus one row per distinct delivered (edge,fact) relation: O(F+D). Sparse composite interning deduplicates those relations; no hash map keyed solely by a dense ID is introduced. Original call/capture ranges are copied once, not per substitution.

The additional actual/binding witness rows distinguish finite original call/input/formal-fact or binding relations; they do not add a caller stack, capture-value tuple or concrete generic instantiation. Existing finite anchor/origin/selector/input/W/S/control observations and documented sparse-query/Q² dependency bounds remain the authority. Do not advertise strict raw-source-linear complexity for the whole compact solver or hide extra transitive closure in a new work allowance. Counters expose source copied rows/words, solver copied rows INCLUDING the separate Q-row finalized status table, derivations and actual/binding witness edges. Counts must reconcile against every actual owned directory length, not merely a subset of SoAs. Inspect work before accepting any future consumer extension.

Transport witnesses are deduplicated composite relations; there are at most one per actual symbolic substitution delivery plus one per bound input query, hence O(D+Q) additional rows. Retaining all alternatives is a shared dependency graph, never enumerated root-to-leaf paths. No environment Cartesian product or per-path source clone is allowed. Subsequent native role execution requires a separate reviewed factored invocation rule; this milestone supplies no such shortcut.

    entry-role-transfers schema=1 evidence=owned-source answerValidation=structural entryComplete=false invocationComplete=false

It reports directory/work counts and exact transfer/capture/source-call witness identities. Normal existing sections/prefix remain byte-identical. Output ordering follows stable original directory IDs; cold/warm/jobs/roundtrip/relocation must match. Legacy suffix validators must admit only the exact new header and known row grammar/counts, never truncate unknown text. Public emitted JavaScript and public native refusal are unchanged.

Primary actual-source oracle lives under tests/corpus: same make/record/lambda site produces foo with first and bar with second, aliases/known forwarders and mixed bound/unbound declarations. Select each real entry separately, query in both source orders and assert different exact anchor/callback/capture/actual-call witnesses, including private equal-type/rung realm leaves where a semantic supplement needs distinct identities. No native masks are injected into production. Actual inspector tests also retain original fields/capture positions/control residuals and no partial output on source failure.

Semantic supplements exercise returned owned evidence after arena destruction/growth, Graph.finish entry remapping, reset/reuse and injected allocation failures. Tampered anchor/input/call actual ordinal/field selector/transfer inventory must fail exact construction/accessor checks or remain explicit unproved evidence; no altered source authority is accepted. Full callable consumer/native/C/ownership/Wire/HostFree/EntryHost/launch proofs stay unavailable.
