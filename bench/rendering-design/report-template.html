Observed compiler limits

What this measures

Generator and strategies

  • Ten UI families: keyed lists, forms with validation, tabs, nested helpers, recursive threads, counter/toggle clusters, sortable tables, modals, input filters and derived summaries.
  • Every component has typed beni Model, Msg, update and view source. Seeded variation changes labels, fields, nesting, thresholds and multi-field writes. The stress sweep uses exactly the original catalogue, with no padding or large random strings.
  • Today TEA/direct are actual release compiler outputs. A erases local messages; B uses static dirty bindings; C uses local reducers; D uses explicit cells. Their read/write and edit analyses consume real compiler BIR.
  • Vanilla independently implements the shapes using shared configurable factories. Actual Solid 2 rc.9 ports cover list and form only. Other family/strategy cells are intentionally absent.

Accounting and limits

  • Whole-response brotli quality 11, gzip 9, and raw bytes after the same Terser 5.51.2 settings. Rendering excludes core/List/Task/Schema/Http source-map spans. Full executable bundles and original compiler-release prices are retained separately.
  • Runtime compressed alone is not additive with app code compressed alone. An OLS intercept is not a measured runtime floor. Unmapped source-map gaps inherit their enclosing declaration.
  • The finite catalogue repeats shapes as N grows. These curves cannot establish the ranking for arbitrary new application features. Vanilla’s factory sharing is a real advantage in this workload.
  • The prototype admits generator-identical roots and a pure-call allowlist. It is not a general ownership proof or a full effects platform. Direct has a known nested-helper failure, #189; its emitted bytes remain shown.
  • The earlier small-app study checked behavior. This extension measures size only; it does not claim every stress-sized DOM was exercised. Speed results are deliberately omitted. No repository gates or suites are run.
