beni examples

Programs written in beni and compiled to JavaScript for the browser-tea platform. Each page runs the compiler's --release output as it is. No bundler and no framework are added.

  • Sternhalma

    Chinese Checkers for two, three, four or six players, by Lucas (rvcas).

    Source · Original · Licence (BSD-3-Clause)

  • Bike Wars

    A two-player light-cycle game on one keyboard, by Ossi Hanhinen.

    The port leaves out the original's one Debug.log, because a release build refuses Debug. Source · Original · Licence (BSD-3-Clause) · Package licences

  • Conduit

    The RealWorld example app, a Medium clone with a feed, articles, comments, profiles and an editor, written the way elm-spa-example writes it.

    It talks to a public demo API, https://api.realworld.show, which the RealWorld project runs. Accounts and articles made there are public, and the API can be down. The page uses the RealWorld project's Conduit theme, inline in its page shell. Only its fonts load from another host, Google Fonts. Source · elm-spa-example · Licence (MIT) · Theme: RealWorld (MIT), Ionicons (MIT)
