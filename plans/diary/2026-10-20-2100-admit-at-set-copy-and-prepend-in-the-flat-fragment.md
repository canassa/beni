## 2026-10-20 21:00 CEST — admit at, set, copy and prepend in the flat fragment

**What I did.** The next #165 slice: `FlatANF0` gains `at`, `set`, `copy` and `prepend` on flat integer lists (`ListPrimitives` in `Primitives.lean`). `at` reads the element at the index, or the fallback for a negative or out-of-range index (`atResult`), and both runtimes record that integer as a read, like `length`; the checker returns the join of the element abstract and the fallback's. `set` is a counted write like `push` with the list after the write (`setResult`), unchanged for a negative or out-of-range index, in which case the counter does not move; its demand and frame are the push's. `copy` is the literal case at the receiver's contents. `prepend` records a read of the base on both sides (the value runtime observes the list, the heap runtime its snapshot) and allocates the copy with the item in front, which the checker names by the fresh site root and the base's origins. A dead receiver returns bottom in the checker, as a push does. Six probes with 16 `#guard` lines check the cases at build time; `prependAlias` shows a conservative refusal (the result is named by the base's origins) where both runs agree. Lists of lists stay out: they need the real exclusivity certificates through nested arrays.

**What I learned.** A multi-line `if` inside a structure instance does not parse (the parser expects the closing brace at the line break before `else`); one line, or a definition, is needed. A `simp` set that unfolds a state abbreviation in the goal must also unfold it in the hypothesis that rewrites the goal (`simp only [abbrev] at h` first), or the two never match. The `BEq` test of a counted write (`previous == stored`) stays in the state as an `if`; stating the written array through a definition (`setResult`) and rewriting the runtime's `if` to it keeps one shape on both sides.
