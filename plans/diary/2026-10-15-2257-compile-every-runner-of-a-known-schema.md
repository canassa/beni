## 2026-10-15 22:57 CEST — compile every runner of a known schema

**What I did.** Closed #175 and #177 on top of schema slice A (#181). A declaration now emits one worker set per operation — `parse`, `print`, `decode`, `encode`, `read`, `write` — each a reachability member of its own, written by one generator over the operation's ends (`SchemaGraph.Op`: decoding or not, host input, host output, JSON). `read` tests every key with `Object.hasOwn` and never keeps the array it was handed; `write` builds objects with `Object.create(null)` and writes NaN; `decode`/`encode` skip the shape tests a type already proves. `decodeWith` … `writeWith` branch on the engine like `parseWith`. Descriptions are now nodes made by core-private `described…` values, no builder and no `box`, so `describe` of a declaration ships no interpreter either; the forced library path boxes them. The root wrappers (`S.parse`/`S.parseWith`, `S.print`/`S.printWith`) became their own members (#177). Specified first in `schema.md` §6 (dated amendments), with §16 *As built — every runner*. Fixtures `run/SchemaRunners` and `run/SchemaDescribeDeclared` (compiled-only, goldens equal to master's interpreter), `.compiled-schemas` on `SchemaDeclRecords`/`SchemaDeclTagged`, new lines in `SchemaDeclGeneric` for a run-time argument, `emit/app/SchemaRunnerWorkers`.

**What I learned.** The release optimiser is the size budget's real judge: passing the operation number into `parserOf` (one function for all six) cost Conduit direct +71 brotli, because the folded `a=>a.ra` was no longer inlined and every later short name shifted; and an omitted trailing argument stops it dropping constant parameters. Keeping `parserOf`/`printerOf` and `declared`'s first four arguments exactly as they were put Conduit's release bytes back to master's to the byte, at the price of a duplicated `parserIn`/`printerIn` that only programs running the new runners (or building dynamic schemas, #176) carry. The new runners are 2–9× faster than the interpreter they replace. A mutually recursive pair of tagged declarations crashes the checker on master (#196).
