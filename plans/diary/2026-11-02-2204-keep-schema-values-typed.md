# Keep Schema values typed

Replaced Schema's erased metadata and callback records with typed nodes,
structural adapters, conversions and workers. Heterogeneous traversal values
use the approved Any envelope, guarded by exact endpoint identities. Reported
input still uses the separate checked data projection only on failures.
Recursive node bodies use typed references to bound ownership summaries.

Specialised worker adapters translate their local failure marker to typed
Maybe results. Source compositions remain compiled. Validator plans retain
readers, child plans and constructor callbacks in typed storage. Generated
Data/Json operations supply host tests and JSON parsing; only SyntaxError is
translated. Imported schema members now retain returned callback effects.

The focused Schema corpus passed 134 program runs, including development,
release and forced-library execution. Native-binding validation and the
schema-plan cache round-trip passed. Behavioural goldens were unchanged;
reviewed ownership reports and the new callback fixture were recorded.

This is a delivery checkpoint: HostFree remains off while the renderer and
Worker families migrate. The checked reporting boundary still needs compiler
support for native values whose runtime representation is a plain scalar.
Full gates and run hashes remain for the final default-on checkpoint.
